# 00 — 브리프: chaebo (채보)

## 한 줄 정의 (one-liner)

> 유튜브 링크나 음악 파일을 넣으면 악기별로 소리를 분리해, 원하는 악기만 골라 듣고(솔로/뮤트)
> 피치 유지 배속으로 돌려 들으며 **귀 채보(악기 카피) 연습**을 하는 개인용 로컬 도구.

## 문제와 대상

- **문제**: 곡을 악기로 따려면 원곡에서 내 악기 소리만 크게·느리게 들어야 하는데,
  이걸 다 해주는 도구(Moises)는 유료 구독이고 무료 도구(UVR5)는 분리만 되고 연습 기능이 없다.
- **대상 사용자**: 사용자 본인 1인 (비전문가 — UI·문서 쉬운 말). **주력 악기 = 베이스**
  (다행히 분리 품질 최상 스템, SDR ~14.8). 드럼·건반/신스·기타도 지원.
- **핵심 가치**: 무료·로컬·무제한으로, 넣으면 바로 "내 악기만 크게 + 느리게" 연습 환경이 나온다.

## 방향 (tone & direction)

- **느낌**: 연습실처럼 단순·집중. 버튼 몇 개(악기 뮤트/솔로·배속·구간반복)가 전부인 화면.
- **참고/유사 사례**: Moises(연습 UX 벤치마크), UVR5(로컬 분리), Transcribe!(구간반복 연습).
  포지셔닝 = Moises 복제가 아니라 **무료·로컬·무제한 + 오픈소스 SOTA 분리 품질**.
- **라이브러리 관리 포함**(사용자 확정): 분리는 느리므로(CPU 곡당 몇 분) 처리한 곡을
  저장·목록화해 언제든 다시 연습.

## 제약 (constraints)

- **배포 프로파일**: `local` (개인 PC·Windows. 공개 서비스 아님)
- **스택 선호/금지**:
  - 분리 백엔드 = ZFTurbo MSST(MIT) + BS/Mel-RoFormer 계열 (조사 검증 SOTA).
    **Demucs 채택 금지** — 2025-01 아카이브된 죽은 라인(CPU 속도 참고치로만).
  - UI = **로컬 웹앱** 우선(브라우저 `preservesPitch` 로 피치유지 배속 무료 — 조사 검증).
    *(게이트 열린 결정: 사용자가 "본 건 앱이었다" — 후일 Tauri 포장 여지 있음)*
- **비기능 제약**:
  - **GPU 유무 혼재**: 주 PC = 내장그래픽(Intel Iris Xe, 실측 확인 — NVIDIA 없음), GPU PC 별도 존재.
    → GPU 자동감지 + CPU 폴백 + 분리 진행률 표시 + 분리는 비동기(UI 안 멈춤) 필수.
  - 건반/신스 분리는 기술 최약점(Other 스템 SDR 9.0) — 품질 기대치를 UI 에서 정직하게 표시.
  - yt-dlp 유튜브 추출은 **개인 연습·비공유 한정**(법적 범위 미검증 — 09-risks 에 명시).
  - 커뮤니티 모델 가중치 라이선스 개별 확인(비상업 조건 존재 가능).

## 비목표 (non-goals)

- 공개 서비스·계정·클라우드 (개인용 로컬 전용)
- 모바일 앱
- 완벽한 건반/신스 분리 (기술적으로 불가 — 기대치 조절이 설계의 일부)
- 악보/타브 자동 생성 (채보는 귀로 하는 것 — 도구는 듣기를 돕는 데 집중)
- DAW 급 스템 편집 (RipX 영역 — 우리는 연습 도구)
- 공유·내보내기·재배포 기능 (저작권 리스크 회피)
