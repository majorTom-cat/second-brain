## 법적 유의 (yt-dlp / 조사 미검증 #1)

- **한국 저작권법상 사적복제 범위는 미검증** — 이 도구는 다음 원칙으로 리스크를 구조적으로 줄인다:
  ① 개인 연습 전용(비목표: 공유·내보내기·재배포 기능 자체를 만들지 않음)
  ② 다운로드 원본·스템은 로컬 디스크에만 존재
  ③ UI 상시 고지(REQ-SEC-002)
- 공개 배포(오픈소스 공개 포함)를 하게 되면 이 항목을 반드시 재평가한다 — 그 전까지 개인 사용 한정.

## 보안

- 기본 바인딩 127.0.0.1(REQ-SEC-001) — 로컬 전용, 인증 없음이 허용되는 유일한 근거.
- 외부 API 키 없음(전부 로컬 처리) — .env 에 넣을 시크릿이 생기면 그 시점에 재검토.
- 업로드 파일 확장자·크기 검증(REQ-ING-003). 파일명은 저장 시 정규화(경로 조작 방지).
- yt-dlp 는 subprocess 인자 배열로 호출(셸 인젝션 방지).

## 프라이버시 경계

- 어떤 데이터도 외부로 전송하지 않는다(다운로드 제외 아웃바운드 없음). 텔레메트리 없음.
- 회사 자산·사내망과 무관한 개인 프로젝트 — 사내 데이터 인제스트 금지(레일 공통 규율).
