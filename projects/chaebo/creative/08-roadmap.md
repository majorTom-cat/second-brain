- **범위**: SP-1(MSST 설치+CPU 실측) · SP-2(체크포인트 라이선스) · SP-3(`<audio>` 동기 실측) — 02-requirements 하단.
- **검증**: 각 스파이크의 실측 숫자(처리시간·드리프트 ms)와 판정(진행/모델 교체/엔진 교체)을 기록.

## 불변 원칙 (모든 Phase 에서 항상 참)

- 시크릿은 코드에 없다(.env — 단 이 프로젝트는 외부 API 키 자체가 없어야 정상).
- 모든 P0 REQ 는 acceptance 에 매핑된 통과 테스트가 있다.
- `/api/health` 유지 · 기본 바인딩 127.0.0.1.
- **Demucs 를 새 의존성으로 추가하지 않는다**(죽은 라인).
- 다운로드 원본·스템은 로컬에만 존재(클라우드 업로드·공유 기능 금지 — 비목표).
- 건반/신스 품질 한계 고지는 제거하지 않는다(정직 UI).
- SyncPlayer 인터페이스(load/play/pause/seek/setRate/setStemVolume)를 우회하는 재생 코드를 만들지 않는다(엔진 교체 가능성 보존).
