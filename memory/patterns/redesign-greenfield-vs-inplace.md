# 패턴 — 전면 리디자인은 그린필드, 점진 델타는 인플레이스 (기존 코드 중력)

> 승격: 2+ 프로젝트 반복(`agora`→`intra` 가 직접 증거 — agora 의 인플레이스 v4.1 리디자인이 빗나가 **intra 그린필드로 재시작**). 열린 구조(결정·계기·트레이드오프·언제 같게/다르게).
> 출처: `archive/agora/knowledge.md`("기존 코드 관성이 새 디자인을 옛 UI로 끌어당긴다"), `memory/lessons/intra.md`, second-brain `intra` 가 그 재시작 산출물.

## 결정 (무엇)
운영 중인 프로젝트에 **새 디자인/요구**가 들어올 때 "기존 코드를 수정(인플레이스)할지 새로 시작(그린필드)할지"를 **설계 거리(design distance)로 먼저 판정**한다 — "수정이 빠르다"는 디폴트를 *모든* 변경에 적용하지 않는다.

- **점진 델타**(필드 추가·정책 변경·백엔드 로직·부분 화면 수정, IA/셸 유지) → **인플레이스 수정**이 맞다(누적 자산 재사용).
- **전면 비주얼/IA 리디자인**(레이아웃·내비 골격·정보구조가 바뀜) → **그린필드**(또는 최소한 셸·IA·내비를 새 디자인에서 *처음부터* 다시 세운다).

## 계기 (왜 — 무엇이 이 교훈을 만들었나)
agora 는 PRD v4.1(전면 리디자인) 인테이크에서 "기존 수정 vs 새로 구축"을 물어 **기존 수정**을 택하고 운영 main 격리 브랜치(`redesign/v4.1`)에서 v3.0 코드에 델타를 얹었다. 백엔드·정책·테스트(177 green)는 진척됐으나, **새 디자인을 입히는 단계에서 산출 화면이 자꾸 기존 v3.0 UI 와 비슷하게** 흘러 받은 디자인과 계속 어긋났다. 원인 = **기존 컴포넌트·레이아웃·내비 골격을 재사용하는 손이 새 디자인보다 익숙한 옛 패턴을 자동 재생산**(코드 중력/gravity). 결국 인플레이스 리디자인을 **폐기하고 `intra` 를 그린필드로 새로 시작**했다. → "수정이 빠르다"는 디폴트가 *전면 리디자인에서는 빗나갔다*.

## 트레이드오프
- **인플레이스의 매력(함정)**: 누적 자산(컴포넌트·테스트·배선)을 재사용해 *처음엔* 빨라 보인다. 하지만 전면 리디자인이면 그 자산이 **옛 IA 로 끌어당기는 닻**이 되어, "비슷하게 나옴 → 고침 → 또 비슷"의 보이지 않는 재작업으로 *결국 더 느려지고* 방향이 어긋난다.
- **그린필드의 비용**: 인증·배포·불변식·검증된 백엔드 패턴을 다시 세워야 한다. → **완화**: 그린필드라도 *코드를 복사하지 않고 prior-art 지식만 인용*(agora→intra 가 정확히 이 방식 — 배포·인증·보안·불변식 패턴을 `archive/agora/knowledge.md` 로 가져오되 화면/IA 는 새 디자인에서). [[external-project-layout]]·[[design-ready-skin]]·[[intranet-deploy]]·[[constraints-as-truth]] 가 그 "지식만 이식" 의 운반체.

## 언제 같게 / 언제 다르게
- **같게(인플레이스)**: 변경이 *기능 델타*다(필드·정책·API·백엔드), 화면 골격·IA·내비는 유지. → 기존 코드에서 진행. 단 **요구가 "변경"인지 "신규"인지 코드 grep 으로 그라운딩**(agora 가 "주행거리 보정"을 기구현으로 오인 → 실은 신규). 가정 금지.
- **다르게(그린필드/셸-퍼스트)**: 비주얼·IA·내비가 *전면* 바뀐다. → 그린필드, 또는 인플레이스를 택했다면 **디자인-퍼스트**로:
  1. **셸+골격(GNB·레이아웃·정보구조)을 프로토타입대로 *먼저* 가시화**하고 방향 확인(조기 게이트).
  2. 화면별로 **옛 화면이 아니라 받은 디자인과 대조**, 깊이 들어가기 전에 "이게 새 디자인처럼 보이나?"를 게이트.
  3. 비주얼은 토큰으로 나중에 흡수해도([[design-ready-skin]]) **골격은 처음부터 새 디자인**.
  4. '기존 컴포넌트에 맞추기' 반사를 금지(코드 중력 차단).
- **판정 신호(인플레이스가 빗나가는 중)**: 산출 화면이 받은 디자인이 아니라 *옛 화면*과 닮아 보인다 / "새로 할까?" 회의가 자꾸 나온다 / 백엔드·데이터 델타부터 손대 화면이 그대로다 → 그린필드/셸-퍼스트로 전환할 신호.
