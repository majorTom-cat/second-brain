# 패턴 — LLM 공급자 추상화 + tier 폴백 + 비용안전 다층게이트 (R4b 토대)

> 승격: 2026-06-18 (`/retro` 아카이브 채굴). 근거: `archive/llm-wiki/knowledge.md`(4공급자 추상화·폴백·유료전환·BYOK·함정 과금게이트·AVX)·`archive/llm-wiki/ideas.md` 스파크들. ⚠️ company-internal 일반화.

## 문제
비용·프라이버시·품질에 따라 LLM 공급자를 바꿔야 하는데,
무료↔유료 공급자가 섞이면 폴백 경로에서 실수로 과금이 발생한다.
약한 모델에 무거운 작업을 주면 조용히 품질이 떨어지거나 실패한다.

## 패턴

① **공급자 추상화**: 단일 인터페이스(`callStructured` 형태)로 여러 공급자(클라우드 API·로컬 서버·구독 CLI 등)를
  구조화 JSON 출력으로 통일한다. `.env`의 `INGEST_PROVIDER`/`QUERY_PROVIDER` 만 바꿔 코드 무수정 전환.
  전역 단일 변수보다 역할별 변수를 우선한다(인제스트와 질의는 최적 공급자가 다를 수 있다).

② **자동 폴백**: 1순위 공급자 한도(429)·오류 시 같은 역할의 백업으로 재시도.
  **서빙 모델 tier에 맞게 프롬프트를 재선택**한다 — 백업이 약한 모델이면 무거운 편집셋을 주지 않는다.

③ **컨텍스트 예산 관리**: 모델별 무료 TPM 한도에 맞춰 입력 페이지 수를 줄인다.
  413(초과) → 같은 모델 축소-재시도. 엉뚱한 무료 공급자로 캐스케이드하지 않는다.

④ **★유료 비용안전 다층게이트**: 폴백을 유료 공급자 안에 가두고 무료로 캐스케이드 금지.
  UI에 '유료' 뱃지 + 확인 팝업. 기본은 무료 유지. 관리자 일일 토큰 상한 설정.
  "키를 넣으면 자동 활성" 구조는 경고 없이 실수 과금 위험 — 명시적 opt-in 필수.

⑤ **BYOK 키 저장**: API 키는 `.env`가 아니라 DB AES-256-GCM으로 암호화 보관
  (마스터키는 env 전용 — DB 유출 시에도 복호화 불가). 429 시 다음 키로 자동 회전.
  env 폴백 무회귀(점진 도입 가능). 화면·로그·에러 메시지에 키 값 미노출.

⑥ **⚠️런타임 CPU 함정**: 일부 구독 CLI는 배포 노드의 CPU 명령어셋에서 막힐 수 있다.
  예: Bun 컴파일 CLI는 AVX 필수 → 구형 노드에서 `SIGILL` 크래시.
  Rust 컴파일 CLI는 이 문제 없음. **배포 전 `lscpu` / AVX 확인을 체크리스트로** 남긴다.

## 신호 (이 패턴을 써야 할 때)
- 다공급자 LLM 통합, 무료↔유료 혼합, 비용·프라이버시 라우팅 설계 시.
- "공급자가 바뀌어도 코드를 건드리기 싫다" 또는 "과금이 모르게 나가면 안 된다" 가 조건으로 나올 때.
- second-brain **R4b** 라우팅 엔진(`rails/route.mjs` + `.env`) 스펙 작성 전.
